## Task 25 – Linux Memory Forensics

### a) What is the exposed password that we find from the bash history output?

  ```bash
  vol.py -f linux.mem --profile="LinuxUbuntu_5_4_0-163-generic_profilex64" linux_bash
  ```
* **Reasoning:** Examined bash session memory dump using Volatility to recover command-line arguments. Found a MySQL login with password in plaintext.
* **Flag:** `NEhX4VSrN7sV`

### b) What is the PID of the miner process that we find?

* **Command Used:**

  ```bash
  vol.py -f linux.mem --profile="LinuxUbuntu_5_4_0-163-generic_profilex64" linux_pslist | grep miner
  ```
* **Reasoning:** Searched for any process name with "miner". The PID was clearly listed in the results.
* **Flag:** `10280`

### c) What is the MD5 hash of the miner process?

* **Commands Used:**

  ```bash
  mkdir extract

  md5sum extract/miner.10280.0x400000
  ```
* **Reasoning:** Dumped the memory region of the process and used `md5sum` to generate the hash. This helps in verifying malware signatures.
* **Flag:** `153a5c8efe4aa3be240e5dc645480dee`

### d) What is the MD5 hash of the mysqlserver process?

* **Command Used:**
