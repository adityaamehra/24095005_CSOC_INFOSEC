def extended_gcd(p,q):
    if p == 0:
        return (q, 0, 1)
    else:
        (gcd, u, v) = extended_gcd(q % p, p)
        return (gcd, v - (q // p) * u, u)

12.) Modular Arithmetic 1:-

code :-
This problem is different from normal modular process because it involves modular congruence. If you haven’t noticed, the two equations given contain ≡ instead of the normal =. ≡ denotes modular congruence and one of its properties is if a ≡ b mod n, then b ≡ a mod n. Moreover, congruence means that a and b has the same equivalence class.
Let’s find the value of a
11 ≡ a mod 6 is same as a ≡ 11 mod 6
11 mod 6 is 5 so we now have the value of a.
To verify that they are congruent, they should have the same equivalence class
11 mod 6 = 5 (equivalence class for 5)
5 mod 6 = 5 (equivalence class for 5)
This means that a and b (a = 5 and b = 11) are both in the same equivalence class.
Repeat the process for the given equation and we’ll have 4.
